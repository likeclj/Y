# Y - 个人自动化脚本合集

> 自用脚本仓库，主要用于阅读类 App 和部分短视频平台的日常任务自动化。

## 包含内容

| 文件 | 说明 |
|------|------|
| `youth.js` | 中青阅读 |
| `qqreads.js` | 企鹅阅读（QQ阅读） |
| `weibo.js` | 微博 |
| `Auto_Kuaishou.js` | 快手极速版 |
| `jzread.js` | 其他阅读相关 |
| `jd_Evaluation.py` | 京东评价相关 |
| `sendNotify.js` | 通知推送模块 |
| `raw_scripts_ttl.js` | 辅助脚本 |
| `Picsew.js` | 图片相关工具 |

## GitHub Actions

仓库内配置了部分定时任务工作流（`.github/workflows/`），可用于自动执行脚本。

## 使用说明

本仓库为**个人自用**，脚本可能依赖特定环境变量、Cookie 或代理工具（如 Quantumult X、Surge 等）。  
请根据自身情况修改配置后再使用。

## 注意事项

- 脚本较旧，部分平台规则可能已变更，使用前请自行测试
- 请遵守相关平台的服务条款，合理使用
- 不提供技术支持
